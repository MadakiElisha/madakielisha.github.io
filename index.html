Firmware-Embedded VTOL NMPC & SINDy Controller

Architected and integrated a real-time C++ flight control module (vtol_nmpc_control) directly into PX4 firmware. Inheriting from px4::ScheduledWorkItem, the module solves nonlinear model predictive control trajectories onboard using acados solvers and data-driven physics identification (SINDy) to handle quadplane transition dynamics. 

class VtolNmpcControl : public ModuleBase<VtolNmpcControl>, public px4::ScheduledWorkItem
{
private:
    void Run() override;
    quadplane_nmpc_solver_capsule *_capsule{nullptr};

    uORB::Subscription _local_pos_sub{ORB_ID(vehicle_local_position)};
    uORB::Subscription _attitude_sub{ORB_ID(vehicle_attitude)};
    uORB::Publication<actuator_motors_s> _actuator_motors_pub{ORB_ID(actuator_motors)};
};

Cryptographic Telemetry Layer & Fleet SDK

Implemented a low-overhead cryptographic module (MavlinkCrypt) directly inside the autopilot firmware alongside a vehicle-agnostic SDK abstraction layer. Provides authenticated encryption (AEAD) for command links and multi-agent swarm state transmissions with safe memory zeroing (crypto_wipe) upon session teardown. 

MavlinkCrypt::~MavlinkCrypt()
{
    // SAFE WIPING OF ALL ENCRYPTION KEYS FROM RAM UPON TEARDOWN
    crypto_wipe(_secret_key, 32);
    crypto_wipe(_public_key, 32);
    crypto_wipe(_shared_key, 32);
    crypto_wipe(_session_key, 32);
}
