Research Manifesto & Technical Directives

Bridging Bare-Metal Control with Embodied Intelligence

Modern autonomous flight cannot rely solely on static PID gain schedules and hand-tuned dynamic models. High-agility uncrewed systems operating in unstructured, GPS-denied environments require high-frequency bare-metal flight execution coupled with on-device neural perception and data-driven trajectory planning. My architectural work focuses on four primary engineering thrusts:

01 / DYNAMIC CONTROL & DENSITY IDENTIFICATION

Nonlinear MPC & Data-Driven Physics (SINDy-MPC / NNPC)

Replacing legacy PID cascades with real-time C++ nonlinear model predictive control. Implementing Sparse Identification of Nonlinear Dynamics (SINDy) and Neural Network Predictive Control (NNPC) directly in PX4 flight loops to continuously adapt to aerodynamic shifts, payload variations, and structural transitions.

02 / EMBODIED PERCEPTION & STATE ESTIMATION

Edge Neural Vision & Visual Inertial Odometry

Deploying hardware-accelerated deep neural networks (YOLO / DeepSORT) alongside Visual-Inertial Odometry (VIO) on edge companion compute. Computing continuous 3D target offsets and visual spatial positioning to drive closed-loop autonomous setpoints without external motion capture.

03 / MULTI-AGENT ARCHITECTURE

Decentralized Vehicle-Agnostic Swarm Engines

Architecting decentralized multi-UAV coordination layers via ROS 2 and MAVLink. Facilitating autonomous agent negotiation, dynamic swarm task distribution, and resilient operation in environments completely disconnected from Ground Control Stations (GCS).

04 / AUTOPILOT CORE & SECURITY

Proprietary Firmware SDKs & Cryptographic Layers

Extending open-source PX4 and ArduPilot internal firmware architectures. Developing custom C++ uORB modules, high-performance proprietary SDK abstractions, and zero-trust telemetry encryption protocols (AEAD) with hardware-enforced memory wiping.

Bare-Metal Firmware & GNC

Firmware-Native VTOL NMPC & Dynamic Solver Module

Architected and integrated a real-time C++ control module (vtol_nmpc_control) directly into the PX4 internal microsecond loop pipeline. Inheriting from px4::ScheduledWorkItem, the module bypasses standard PID controllers to solve optimal quadplane VTOL transition dynamics on-the-fly using acados dynamic capsules.

src/modules/vtol_nmpc_control/vtol_nmpc_control.hpp PX4 Microsecond Loop 
class VtolNmpcControl : public ModuleBase<VtolNmpcControl>, public ModuleParams, public px4::ScheduledWorkItem
{
private:
    void Run() override;
    quadplane_nmpc_solver_capsule *_capsule{nullptr};

    // Subscriptions to core PX4 microsecond uORB topics
    uORB::Subscription _local_pos_sub{ORB_ID(vehicle_local_position)};
    uORB::Subscription _attitude_sub{ORB_ID(vehicle_attitude)};
    uORB::Subscription _vtol_status_sub{ORB_ID(vtol_vehicle_status)};
    uORB::Subscription _trajectory_setpoint_sub{ORB_ID(trajectory_setpoint)};

    // Direct motor actuator publication
    uORB::Publication<actuator_motors_s> _actuator_motors_pub{ORB_ID(actuator_motors)};
};

Security & Abstraction Architecture

Cryptographic Telemetry Layer & Proprietary Fleet SDK

Developed an onboard firmware cryptographic engine (MavlinkCrypt) and vehicle-agnostic SDK abstraction layer. Secures real-time command links and multi-agent swarm state transmissions over untrusted wireless channels using AEAD encryption with explicit, zero-latency memory wiping (crypto_wipe) on session teardown.

src/modules/mavlink/mavlink_encryption.cpp PX4 C++ Security Module 
MavlinkCrypt::~MavlinkCrypt()
{
    // SAFE WIPING OF ALL ENCRYPTION KEYS FROM RAM UPON TEARDOWN
    crypto_wipe(_secret_key, 32);
    crypto_wipe(_public_key, 32);
    crypto_wipe(_shared_key, 32);
    crypto_wipe(_session_key, 32);
}
