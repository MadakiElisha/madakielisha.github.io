Bare-Metal VTOL NMPC & SINDy-MPC Controller

[C++, PX4 Firmware, acados, SINDy, uORB]

Architected and integrated a real-time C++ flight control module (vtol_nmpc_control) directly into the PX4 microsecond internal pipeline. The module replaces legacy PID loops with nonlinear model predictive control, utilizing data-driven physics identification (SINDy) to dynamically compensate for structural transition dynamics in quadplane VTOLs.

src/modules/vtol_nmpc_control/vtol_nmpc_control.hpp PX4 C++ Microsecond Loop

Firmware MAVLink Encryption & Proprietary SDK Layer

[C++, PX4 MAVLink, AEAD, Fleet SDK]

Developed an onboard cryptographic module (MavlinkCrypt) and proprietary SDK abstraction layer. Secures real-time command, control, and multi-agent swarm state exchanges over untrusted wireless links using AEAD encryption and secure key wiping.

src/modules/mavlink/mavlink_encryption.cpp PX4 C++ Implementation 
MavlinkCrypt::~MavlinkCrypt()
{
    // SAFE WIPING OF ALL ENCRYPTION KEYS FROM RAM UPON TEARDOWN
    crypto_wipe(_secret_key, 32);
    crypto_wipe(_public_key, 32);
    crypto_wipe(_shared_key, 32);
    crypto_wipe(_session_key, 32);
}
