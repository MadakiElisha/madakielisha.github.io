Firmware-Embedded SINDy-MPC Autopilot

[C++, PX4, EKF3, NMPC]

Integrated Sparse Identification of Nonlinear Dynamics (SINDy-MPC) directly into PX4 flight firmware. Instead of relying on static linearized models, the system dynamically identifies aerodynamic state matrices $\dot{x} = f(x, u)$ onboard to update MPC control horizons in real time.

$$\dot{x} = \mathbf{\Theta}(x, u)\mathbf{\Xi}$$ Sparse coefficient matrix evaluated on-board at 100 Hz
PX4 uORB Module Snippet (C++)
// SINDy State Identification Loop inside PX4 Module
void SindyMPC::update_state_matrix(const vehicle_local_position_s &pos) {
    matrix::Matrix<float, 6, 10> Theta = build_candidate_library(pos.vx, pos.vy, pos.vz);
    _Xi = solve_lasso_sparse(Theta, _accel_measurement);
    _nmpc_solver.set_dynamics_matrix(_Xi);
}

Embedded Cryptographic Telemetry Layer

[C++, mbedTLS, ChaCha20, AES-256]

Integrated lightweight mbedTLS cryptographic primitives into serial telemetry streams. Designed to secure command links and payload transmission against interception while maintaining microsecond-level timing bounds on bare-metal microcontrollers.

mbedTLS Telemetry Encryption Wrapper (C++)
// Encrypt MAVLink Packet Payload via mbedTLS ChaCha20
int encrypt_telemetry_packet(uint8_t *payload, size_t len, uint8_t *key, uint8_t *nonce) {
    mbedtls_chacha20_context ctx;
    mbedtls_chacha20_init(&ctx);
    mbedtls_chacha20_setkey(&ctx, key);
    mbedtls_chacha20_starts(&ctx, nonce, 0);
    return mbedtls_chacha20_update(&ctx, len, payload, payload);
}
