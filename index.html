Firmware-Embedded SINDy-MPC Autopilot

[C++, PX4, EKF, Linear Algebra]

Implemented dynamic modeling using Sparse Identification of Nonlinear Dynamics (SINDy) directly within PX4 firmware. Instead of relying on static linearized models, the system continuously extracts active state equations $\dot{x} = f(x, u)$ to update MPC prediction horizons in turbulent environments.

$$\dot{x} = \mathbf{\Theta}(x, u)\mathbf{\Xi}$$ Sparse coefficient matrix $\mathbf{\Xi}$ evaluated on-board at 100 Hz
