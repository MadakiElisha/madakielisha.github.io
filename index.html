Research Trajectory & Technical Scope

Traditional autopilot stacks rely heavily on rigid, hand-tuned rule blocks for perception, planning, and control. Inspired by end-to-end embodied intelligence (Wayve, Skydreamer) and game-theoretic neural decision engines (AlphaGo), my work is now focusing on building vehicle-agnostic and environment-agnostic intelligence. By deploying lightweight, on-device neural models alongside microsecond flight control loops, aerial agents can dynamically evaluate unstructured environments, make decentralized decisions, and adapt onboard in real time.

Firmware-Embedded VTOL NMPC Controller

[C++, PX4 Firmware, acados, uORB]

Architected and integrated a custom C++ flight control module (vtol_nmpc_control) directly into the PX4 firmware pipeline. Inheriting from px4::ScheduledWorkItem, the module subscribes to uORB topics, updates an acados quadplane solver capsule, and publishes motor allocations.

src/modules/vtol_nmpc_control/vtol_nmpc_control.hpp PX4 C++ Header 
class VtolNmpcControl : public ModuleBase<VtolNmpcControl>, public ModuleParams, public px4::ScheduledWorkItem
{
private:
    void Run() override;
    quadplane_nmpc_solver_capsule *_capsule{nullptr};

    uORB::Subscription _local_pos_sub{ORB_ID(vehicle_local_position)};
    uORB::Subscription _attitude_sub{ORB_ID(vehicle_attitude)};
    uORB::Subscription _vtol_status_sub{ORB_ID(vtol_vehicle_status)};
    uORB::Subscription _trajectory_setpoint_sub{ORB_ID(trajectory_setpoint)};

    uORB::Publication<actuator_motors_s> _actuator_motors_pub{ORB_ID(actuator_motors)};
};

Firmware MAVLink Encryption Layer

[C++, PX4 MAVLink, AEAD, Memory Zeroing]

Developed an onboard cryptographic module (MavlinkCrypt) to secure telemetry command links. Implemented authenticated encryption routines (crypto_aead_lock), counter-based nonces, and safe memory zeroing (crypto_wipe) upon session teardown.

src/modules/mavlink/mavlink_encryption.cpp PX4 C++ Implementation 
MavlinkCrypt::~MavlinkCrypt()
{
    // SAFE WIPING OF ALL ENCRYPTION KEYS FROM RAM UPON TEARDOWN
    crypto_wipe(_secret_key, 32);
    crypto_wipe(_public_key, 32);
    crypto_wipe(_shared_key, 32);
    crypto_wipe(_session_key, 32);
}
